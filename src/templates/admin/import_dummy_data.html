Import Dummy Data

📋 Data Format

This tool imports dummy data from a JSON file containing:

  • Admin: Username, password, email, name
  • Students: Username, password, name, gender, parent_phone, government
  • Courses: Name, description, units
  • Questions: Text, points, difficulty, type, answers (for MCQ)
  • Exams: Title, type, time_limit, questions
  • Plans: Title, price, validity period
  • Subscriptions: Student, plan, courses

Default JSON file: dummy_data.json in project root

{% csrf_token %}

Warning: This will delete all existing students, courses, exams, questions, plans, and subscriptions.

Or use Command Line

# Import from default file (dummy_data.json)
python manage.py import_dummy_data

# Import from specific file
python manage.py import_dummy_data --json-file=/path/to/data.json

# Clear existing data before import
python manage.py import_dummy_data --clear
